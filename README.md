# Confetti Cuisine 🍳

A cooking class booking website built with **Node.js, Express.js, and EJS**.

Confetti Cuisine is a web development project focused on creating a platform where users can explore cooking classes and get in touch to sign up. The project is being developed step by step, with new features and improvements added throughout development.

## 🚀 Current Features

- Home page introducing Confetti Cuisine.
- Courses page displaying available cooking classes.
- Contact page with a signup form.
- Form submission handling using Express.js.
- EJS templates and reusable page layout.
- Static files served through Express.
- Custom 404 error page.
- Responsive navigation and styling.

## 🛠️ Technologies

- **Node.js** – JavaScript runtime.
- **Express.js** – Web application framework.
- **EJS** – Embedded JavaScript templating.
- **HTML5 & CSS3** – Structure and styling.
- **JavaScript** – Application functionality.
- **Git & GitHub** – Version control.

## 📦 Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Labadi05/confetti-cuisine.git
   ```

2. Navigate to the project directory:

   ```bash
   cd confetti-cuisine
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the application:

   ```bash
   npm start
   ```

5. Open your browser and visit:

   ```text
   http://localhost:3000
   ```
